# Project Charter: JuanMart Data Warehouse & Analytics Platform

**Prepared By:** Lead Data Engineer  
**Date:** July 21, 2026  
**Target Platform:** JuanMart E-Commerce Data Warehouse  

---

## 1. Discovery (Phase 1)
* **Business Problem:** JuanMart executives experience discrepancies between Finance (reporting +15% revenue growth) and Operations (reporting a deficit due to returns/cancellations).
* **Objective:** Establish a single source of truth (SSOT) data warehouse to reconcile sales metrics, track regional trends, handle historical address updates (SCD Type 2), and build executive dashboard reports.
* **Key Stakeholders:** CEO, Finance Team, Operations Team, Logistics Partners.

---

## 2. Data Preparation (Phase 2)
* **Data Sources:** Web customer registration logs, legacy transactional MySQL DB sales logs, and 3PL shipping text files.
* **Data Quality Anomalies Handled:**
  * Exact duplicate record removal.
  * Standardizing inconsistent regional aliases (`NCR`, `ncr`, `Metro Manila` $\rightarrow$ `National Capital Region`).
  * Imputing missing payments using regional median values.
  * Standardizing heterogeneous date formats to `YYYY-MM-DD`.

---

## 3. Model Planning (Phase 3)
* **Data Architecture:** Dimensional Modeling (Star Schema).
  * **Fact Table:** `fact_sales` (Transaction-level metrics: revenue, order count, statuses).
  * **Dimension Tables:** `dim_customer` (SCD Type 2 for tracking address migrations), `dim_region`, `dim_calendar`.
* **Tooling:** Python (Pandas), SQL / PostgreSQL (Warehouse Engine), Streamlit / Plotly (Analytics Dashboard).

---

## 4. Model Building (Phase 4)
* **ETL Pipeline:** Programmatic Python script (`1.2_data_cleansing.py`) for automated cleaning.
* **Business Rules Engine:**
  * **Net Revenue Equation:**  
    $$\text{Net Revenue} = \sum \text{amount\_paid} \quad \text{where } \text{status} = \text{'Completed'}$$
  * **Quarantined Data Error Rate:**  
    $$\text{Error Rate (\%)} = \left( \frac{\text{Invalid or Incomplete Records}}{\text{Total Raw Records}} \right) \times 100$$

---

## 5. Communicate Results (Phase 5)
* **Dashboard Deliverables (Streamlit / Plotly):**
  1. **KPI Summary Cards:** Net Revenue, AOV, Total Orders, Quarantined Error Rate (%).
  2. **Time-Series Line Chart:** Monthly/Quarterly revenue trends via `dim_calendar`.
  3. **Geographic Sales Heatmap:** Sales volume by regional customer locations mapped to SCD Type 2 address history.
  4. **Product Line Breakdown:** Sales volume vs. profit margins by category.

---

## 6. Operationalize (Phase 6)
* **Deployment Plan:** Programmatic ETL deployment with automated data validation triggers.
* **Maintenance:** Periodic staging tables refresh and error log quarantine monitoring.
